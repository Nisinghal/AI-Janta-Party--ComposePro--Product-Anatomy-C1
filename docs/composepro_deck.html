Design Direction

Structure & rhythm, not color.

Type Scale

  • Active Mode: Inter 14px/700, 100% opacity
  • Inactive: Inter 14px/400, 60% opacity
  • Coaching Tips: Inter 15px/500, +0.3px tracking
  • Zoom: JetBrains Mono 13px in pill selector
  • Sub-labels: 10px/700, ALL-CAPS, +1.5px tracking

Spacing Rhythm

  • Base grid: 8pt system
  • Edge margins: 24px
  • Bracket inset: 48px from edges
  • Bottom panel: 200px anchored sheet
  • Shutter: 72×72px, 3px border

State Signaling

  • Active: Font weight 400→700, opacity 60%→100%
  • Success: #34C759 green on horizon, brackets, tooltip
  • Scanning: Bracket pulse animation (2s infinite)
  • Disabled: 20% opacity
Component 2.1

Viewfinder — 3 Variants

Tilt down slightly

A · Idle

Default resting state. Brackets at 60% opacity. Horizon slightly tilted. Tooltip hidden. Shutter ready.

Tilt down slightly

B · Scanning

Active guidance. Brackets pulse. Tooltip appears with coaching text. User adjusts framing.

Hold steady ✓

C · Locked

Composition confirmed. Green horizon + brackets. Shutter scales down. "Hold steady" prompt.

Design Decisions

What we resolved today

Spacing
Floating island vs anchored bottom sheet?
Anchored dark gradient sheet (Pro camera feel)
Typography
Pro technical metrics vs simple zoom labels?
Monospace zoom only — intuitive for general users
Shutter
Flat white circle vs glassmorphism gradient?
Glassmorphism shutter with radial gradient
Success State
Gold/Yellow accent vs green for "locked"?
Green (#34C759) — universal "go" signal
